# 動的音響スウィープ提示機能（180度反対方向からのリアルタイム空間移動）

音源の方向判定をより高精度かつ立体的に感じられるよう、ビート発音ごとに「180度反対方向（例: 8時）から目的方向（例: 2時）」へ音源が飛び抜ける動的スウィープ音響提示機能を導入します。

## ユーザー確認・決定事項の要約

> [!IMPORTANT]
> ユーザー様との質疑応答により確定した仕様です。

- **移動軌道パターン**: 180度反対側から目的方向への直線スウィープ（例：目的方向が2時の場合、8時から2時へ音源が高速移動）。
- **機能の統合方式**: コントロールパネルの「設定」にて「動的スウィープ提示: ON / OFF」を切替可能。
- **音源の表現**: 各ビートの発音時間内（短時間の指向性音）でHRTF PannerNodeの3D座標（x, y, z）および方位角をシームレスにリアルタイム・ランプ遷移（`linearRampToValueAtTime` / 連続補間）。

---

## 1. 概要とコンセプト

- **機能の目的**: 人間の耳の音響心理学的特性（動的耳介・両耳間時間差/強度差の変化に伴う方位知覚の向上）を活用し、静止音では前後錯覚（12時と6時の区別など）が生じやすい課題を、180度対角スウィープ音響の物理移動によって一瞬で明確に認識できるようにします。
- **対象ユーザー**: 視覚障害・ロービジョンの方や、画面を見ずに身体の向き・空間認識を音だけで把握したい実験者・ユーザー。

---

## 2. ユーザー体験（UX）と視覚・音響デザイン

### UX & コントロールUI
1. **設定パネルへの追加**:
   - コントロールパネルに「音響提示モード」または「動的スウィープ提示 (ON/OFF)」のトグルボタンを配置。
   - ONの場合：ビートごとに180度反対方向からターゲット方向へ音像がダイナミックに移動。
   - OFFの場合：現在のターゲット位置に固定された音源提示（従来の通常提示）。

2. **レーダーキャンバス（視覚）での軌道アニメーション**:
   - 動的スウィープがONの際、レーダー上にターゲット位置（例: 2時）だけでなく、反対位置（例: 8時）からターゲットへ向かう残像矢印ライン（点線スウィープライン）を薄く表示し、ビート発振に同期して光が走るエフェクトを追加。

3. **音響デザイン**:
   - ビート発音が開始する瞬間（Time $T_{start}$）に音源位置を $180^\circ$ 対角位置（$-x, -y, -z$）にセットし、ビート発音の終了時間（Time $T_{end}$）に向けて目的位置（$+x, +y, +z$）へAudioParam (`positionX`, `positionY`, `positionZ`) の補間ランプを実行。

---

## 3. 主要な設計上の決定とトレードオフ

- **決定 1: Web Audio API PannerNode の AudioParam リアルタイム遷移**
  - *採用案*: `panner.positionX.setValueAtTime()` および `linearRampToValueAtTime()` / サンプリングステップ毎の連続位置更新。
  - *理由*: 音の途切れ（ポッピングノイズ）を生じさせず、DSPレベルで滑らかな音像のドップラー効果および空間移動感を付与できるため。
  - *代替案*: 複数PannerNodeのクロスフェード（ノイズのリスクとCPU負荷が増加するため却下）。

- **決定 2: トグルON/OFFによる後方互換性**
  - *採用案*: デフォルトはダイナミックな体感を促すため動的スウィープON（または既存操作を妨げない選択可能形式）。
  - *理由*: 静止音でじっくり角度を比較したいニーズと、ダイナミックな移動感で瞬時に方向を把握したいニーズの双方に対応。

## 4. システム構成とデータフロー (Technical Reference)

```
┌─────────────────────────────────────────────────────────┐
│                   PoseTracker / App State               │
│  - ターゲット方向 (Azimuth: 60° / 2時)                   │
│  - 動的スウィープ設定: isDynamicSweepEnabled (true)     │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│               SpatialAudioEngine (Web Audio)            │
│  - ビートトリガー時 (triggerSound):                       │
│    1. 目的座標 (X, Y, Z) から 180°対角座標 (-X, -Y, -Z) 算  │
│    2. PannerNode 位置を (-X, -Y, -Z) に瞬時設定          │
│    3. 音の発音時間 (例: 80ms) 内で                     │
│       (+X, +Y, +Z) へ linearRampToValueAtTime 移動      │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                 3D Spatial Audio Output                 │
│  - HRTF フィルターによるリアルタイム立体移動音響            │
└───────────────────────────┴─────────────────────────────┘
```
